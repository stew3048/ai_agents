三個模型在自訂 5 張圖上的平均指標（統一定義）
指標定義（對三個模型都一樣）：

IoU: ( \text{IoU} = \frac{TP}{TP + FP + FN} )
Precision: ( \frac{TP}{TP + FP} )
Recall: ( \frac{TP}{TP + FN} )
FP rate: ( \frac{FP}{TN + FP} )
FN rate: ( \frac{FN}{TP + FN} = 1 - \text{Recall} )

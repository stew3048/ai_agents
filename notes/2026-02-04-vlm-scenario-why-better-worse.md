# VLM (SAM 2.0) 各情境表現好／壞原因整理

> 依據目前提示策略與對比報告，整理「為什麼 VLM 在個別情境變好／變爛」與「sea-sky / heavy-occlusion 表現不好的原因」。

---

## 一、為什麼 VLM 在 sea-sky-confusable 與 heavy-occlusion 表現不好？

### 1. Sea-sky-confusable（海天混淆）

- **目前提示**：**Box**，框選「上方 0%～50%」整塊（含天空與海天交界）。
- **情境特性**：海與天空顏色、紋理相近，DL 的失敗多是「把海面當天空」的 **FP**。
- **VLM 表現不好的原因**：
  - Box 涵蓋了**海天交界甚至一部分海面**。SAM 的任務是「分割框內物體」，在視覺上天空與海連成一片時，容易：
    - 把框內整塊（天空+海）當成一個物體一起分割出來 → **FP 增加**（海被標成天空）；
    - 或邊界畫在海天之間時不穩定，依圖片不同有時偏上有時偏下 → **IoU 波動**。
  - 也就是：**提示（box）沒有把「只分割天空」的意圖說清楚**，而 SAM 依外觀分割，海天相似時就會混淆，導致平均 IoU 略降（-2.6%）、FP 略升（+6.2%）。

### 2. Heavy-occlusion（嚴重遮擋）

- **目前提示**：**多點**，在「上方 10%、20%、30%」高度，水平 0.25 / 0.5 / 0.75 共 9 個前景點。
- **情境特性**：天空被建築、樹木等嚴重切割成多塊，DL 的失敗包含漏檢天空（FN）與誤把建築邊緣當天空（FP）。
- **VLM 表現不好的原因**：
  - 在嚴重遮擋下，**很多點會落在「非天空」上**（例如建築頂、樹冠、欄杆）。SAM 會「分割該點所在的物體」，因此：
    - 點在建築上 → 分割出建築 → 被算成 **FP**（非天空被標成天空）；
    - 真正的天空在建築之間的縫隙，**沒有被點提示到** → 沒被分割出來 → **FN 大增**。
  - 報告中 SAM 在 heavy-occlusion 的 FP、FN 都約 0.51，代表預測 mask 與 GT 錯位嚴重：**點提示落在遮擋物上，導致既多割了非天空，又漏割了被擋住的天空**。

## 二、各情境「變好」的原因（VLM 優於 DL）

| 情境 | 目前提示 | 變好的主要原因 |
|------|----------|----------------|
| **No-sky** | 無提示（中心點當前景） | DL 靠顏色/亮度，易把亮牆、雪地整片當天空（FP 高）。VLM 依「一點」分割，傾向只割出該點所屬的連通區域，不會整張圖都標成天空 → **FP 大降**（0.42→0.02）。 |
| **Night** | 單點，上方約 20% 中心 | DL 在夜間低對比下邊界不穩、漏檢多（FN 高）。VLM 被明確點在「上方」→ 多半點在天空 → 分割該連通區域即可，不依賴夜間顏色/對比 → **IoU 升、FN 大降**。 |
| **Urban** | Box，上方 0%～40% | DL 把建築頂、玻璃反光當天空（FP 高）。VLM 的 box 明確限定「上方一塊」→ 多半只含天空或天空為主，SAM 在框內分割，較少把下方建築整片納入 → **FP 大降、IoU 明顯升**。 |

## 三、各情境「變爛」的原因（VLM 劣於 DL）

| 情境 | 目前提示 | 變爛的主要原因 |
|------|----------|----------------|
| **Sea-sky-confusable** | Box，上方 0%～50% | Box 含海天交界或海面，SAM 依外觀分割時易把海也算進同一物體或邊界不準 → **FP 略升、IoU 略降**（平均 -2.6%，5 筆中 3 筆惡化）。 |
| **Heavy-occlusion** | 多點，上方 10%～30% | 點常落在建築/遮擋物上，SAM 分割的是「點所在物體」而非「所有天空」；天空被擋住的區塊沒被點到 → **FN 與 FP 都暴增、IoU 大降**（平均 -78.1%，5 筆全惡化）。 |

## 四、對照總表（方便快速查）

| 情境 | VLM 表現 | 變好／變爛原因簡述 |
|------|----------|--------------------|
| No-sky | 變好（FP 大降） | 提示約束強，不會整圖當天空。 |
| Night | 變好（IoU↑ FN↓） | 點在上方天空，不依賴夜間對比。 |
| Urban | 變好（IoU↑ FP↓） | Box 限在上方，少把建築當天空。 |
| Sea-sky-confusable | 略爛（IoU 略降） | Box 含海面，海天外觀相似易混淆。 |
| Heavy-occlusion | 明顯變爛（IoU 大降） | 點落在遮擋物上，漏割被擋住的天空。 |

## 五、後續可調方向（簡要）

- **Sea-sky-confusable**：縮小 box（例如只框上方 0%～35%）、或改為「上方單點 + 負向點在海面」等，減少框內含海。
- **Heavy-occlusion**：改為「僅在明顯天空區」的少數點或小 box，或先偵測天空區再在該區內給點／框，避免點在建築或樹上。

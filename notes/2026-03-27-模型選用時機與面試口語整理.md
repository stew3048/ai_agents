## 二、CNN Decoder 的角色釐清

**問題：CNN Decoder 是用來還原影像，還是萃取局部空間特徵？**

**答案：還原影像（空間還原）**

| 用途 | 典型場景 | 方向 |
|---|---|---|
| 萃取局部特徵 | ResNet / VGG 前幾層 | 影像 → 壓縮特徵 |
| **還原成影像（本專案）** | 語意分割 decoder head | 壓縮特徵 → 空間 mask |

DINOv2 輸出低解析度、高維度的 patch token（例如 16×16 patches, 1536 維），CNN Decoder 負責把它**逐步還原成與原圖等大的 pixel-level 天空機率圖**：

```
DINOv2 輸出        CNN Decoder              輸出
[16×16, 1536維] → 降維 + 空間還原 → [H×W, 1維（天空機率）]
```

各層職責：
```python
conv_block(1536 → 512)   # 1×1 conv：降維，壓縮語意
conv_block(512  → 512)   # 3×3 conv：整合鄰近 patch 關係
conv_block(512  → 256)   # 3×3 conv：進一步萃取邊界特徵
Conv2d(256 → 1)          # 1×1 conv：輸出每像素機率
```

> **DINOv2 負責「看懂語意」，CNN Decoder 負責「畫出邊界」**

## 三、三種模型的使用時機與適用情境

### 3.1 Grounding DINO + SAM
- **時機**：零樣本（Zero-shot），完全無訓練資料
- **優勢**：Recall 高，幾乎不漏掉天空；邊界清晰的影像效果好
- **代價**：FP 高，容易誤報非天空區域；無天空場景推論失敗（TNR 無法計算）
- **適合說法**：「對『不漏掉任何天空』要求高、但能容忍誤報的場景」

### 3.2 CLIPSeg
- **時機**：零樣本，需要更端到端、更穩定的方案
- **優勢**：直接輸出分割熱力圖（不需兩段式流程）；Precision 較高，較少亂報
- **代價**：濃霧、低對比場景信心度下降（entropy 高，機率圖雜訊多）；邊界不夠精細
- **與 Grounding DINO+SAM 的差異**：更端到端，但極端天候下信心度不穩

### 3.3 DINOv2 + CNN Decoder
- **時機**：有標記資料，追求最高精度
- **優勢**：IoU 0.92，FP rate 0.01，無天空場景 TNR = 1.0 完全不誤報
- **關鍵設計**：DINOv2 權重**完全凍結**，只訓練 CNN Decoder → 訓練成本低、效果好
- **適合說法**：「基於通用語意特徵，加上 in-domain 訓練資料讓 decoder 學會特定任務的邊界」

### 決策邏輯
```
有標記資料嗎？
├── 有 → DINOv2 + CNN（最高精度，推薦）
└── 沒有（零樣本）
    ├── 需要高 Recall、不漏掉？ → Grounding DINO + SAM
    └── 需要端到端、高 Precision？ → CLIPSeg
```

## 四、面試口語練習與修正

### 用戶自述版本

> GroundingDINO + SAM 適合用在無訓練資料、zero-shot、想快速看答案，適用於邊界清楚的影像。  
> CLIPSeg 適合用於語意清楚的影像。  
> DINOv2 + CNN 適合基於通用特徵，再加上 training data 來針對特定任務訓練。

### 修正建議

| 模型 | 修正重點 |
|---|---|
| Grounding DINO + SAM | 補充「Recall 高但 FP 高，適合容忍誤報的場景」 |
| CLIPSeg | 補充「比 GroundingDINO+SAM 更端到端；但濃霧等低對比場景信心度會下降」 |
| DINOv2 + CNN | 補充「DINOv2 凍結，只訓練 decoder，訓練成本低」 |

### 修正後精簡版（可直接背）

> 三種模型我都有評估。**Grounding DINO+SAM** 和 **CLIPSeg** 都是 zero-shot，不需要訓練資料，前者 Recall 高但誤報多，後者更端到端但在濃霧等極端場景信心度不穩。最終效果最好的是 **DINOv2 + CNN Decoder**，DINOv2 凍結當特徵提取器，只訓練輕量的 CNN Decoder 來還原 pixel-level 的 mask，在 116 張測試集上 IoU 達到 0.92，無天空場景 TNR 也是完美的 1.0。

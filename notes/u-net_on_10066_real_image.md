# U-Net on SkyFinder Camera 10066 Real Image - 學習心得

> 日期：2026-01-21

## 1. 實驗目標

在真實的 SkyFinder webcam 資料（camera 10066）上訓練 U-Net，並與傳統 CV baseline 進行比較，驗證深度學習在天空分割任務上的優勢。

---

## 2. 資料集

### 2.1 資料來源
- **資料集**：SkyFinder Dataset（Zenodo）
- **Camera ID**：10066
- **資料路徑**：
  - Images: `data/skyfinder_sample/images/`
  - Masks: `data/skyfinder_sample/masks/`
  - Splits JSON: `outputs/splits_10066.json`

### 2.2 資料切分（時間順序切分）
| Split | 數量 | 檔案範圍 | 說明 |
|-------|------|----------|------|
| Train | 35 張 | 001.jpg ~ 035.jpg | 前 70% |
| Val | 7 張 | 036.jpg ~ 042.jpg | 中間 15% |
| Test | 8 張 | 043.jpg ~ 050.jpg | 後 15% |

**為什麼用時間順序切分？**
- SkyFinder 是固定攝影機拍攝的 webcam 資料
- 相鄰時間的影像非常相似（同樣場景、相似光線）
- 如果隨機切分，train 和 val/test 會有高度相似的圖片 → 資料洩漏
- 時間順序切分確保模型真正學到泛化能力

| 參數 | 值 |

| Epochs | 10 |

| Learning rate | 1e-4 |

| Loss | Combined Loss (BCE + Dice) |

- Random Horizontal Flip
- Random Vertical Flip
- Random Crop + Resize

## 6. 多雲傍晚場景分析（041, 042）

這兩張圖是典型的「多雲傍晚」場景，對模型來說是較困難的案例。

### 6.1 041 - 傍晚粉紫天空 + 大片灰雲

**原圖特徵**：
- 上半部：粉紫色天空
- 中間：大片灰色雲層
- 雲層顏色接近山脈

**U-Net Overlay 結果**：
- 大部分天空區域正確（綠色）
- 灰雲邊緣有部分 FN（藍色）
- 模型對「灰雲 vs 山脈」的邊界有些混淆

### 6.2 042 - 傍晚深藍天空 + 厚重灰雲

**原圖特徵**：
- 左上：深藍色天空
- 右側：厚重的灰黑色雲層
- 雲層核心非常暗，接近地面亮度

**U-Net Overlay 結果**：
- 藍色天空區域正確（綠色）
- 厚重灰雲核心有 FN（藍色）
- 挑戰：暗灰色雲 vs 暗色山脈難以區分

### 6.3 多雲場景小結

| 挑戰 | 說明 |
|------|------|
| 灰雲顏色 | 灰色雲與山脈/地面顏色相近 |
| 光線變化 | 傍晚光線使整體偏暗 |
| 邊界模糊 | 雲層邊緣不如晴天清晰 |

**結論**：即使是多雲傍晚場景，U-Net 仍能辨識大部分天空區域，但對於「灰色厚雲」有部分漏判。這是可以接受的，因為連人眼有時也難以判斷那些區域是否屬於「天空」。

## 7. CV Baseline 失敗原因分析

### 7.1 CV Baseline 假設
CV baseline 使用 HSV 色彩空間進行閾值判斷：
- H (Hue): 90-130（藍色範圍）
- S (Saturation): 30-255
- V (Value): 120-255

### 7.2 失敗場景

| 場景 | 失敗原因 |
|------|----------|
| 淡藍霧濛天空 | 飽和度不足，被 S_min 排除 |
| 黃昏橘色天空 | Hue 在 0-30（橘色），超出藍色範圍 |
| 日落粉紅天空 | Hue 在 300-360（粉紅），超出範圍 |
| 灰色雲層 | 飽和度極低，被排除 |
| 夜間深藍天空 | Value 過低，被 V_min 排除 |

### 7.3 根本限制
CV baseline 的根本問題是**假設天空 = 藍色**，但真實世界中：
- 天空顏色隨時間變化（晨昏、日落、夜間）
- 天空可能有雲（白色、灰色、甚至黑色）
- 天空可能被霧氣遮蔽（低飽和度）

---

## 8. U-Net 成功原因分析

### 8.1 學到「天空的語意」
U-Net 不依賴固定的顏色閾值，而是學會了：
- 天空通常在圖片上方
- 天空與地面有明確的邊界（山脈、樹木、建築）
- 天空的紋理特徵（均勻 vs 有雲）

### 8.2 Skip Connections 的作用
U-Net 的 skip connections 保留了高解析度的細節，使得：
- 山脈輪廓可以被精確辨識
- 複雜邊界（樹枝、建築物）也能正確分割

### 8.3 端到端學習
模型直接從 (image, mask) 配對學習，不需要人工設計特徵，自動適應各種光線條件。

## 10. 結論

### 10.1 數據總結
| 指標 | CV Baseline | U-Net | 提升 |
|------|-------------|-------|------|
| Val IoU | 68.31% | **93.45%** | +25.14% |
| 相對提升 | - | - | **1.37x** |

### 10.2 關鍵發現
1. **U-Net 完勝 CV baseline**：在各種天空顏色下都表現優異
2. **無 Overfitting**：Train/Val Loss 差距僅 0.0128
3. **快速收斂**：2-3 個 epoch 就達到 90%+ IoU
4. **多雲場景可接受**：即使是困難的灰雲場景，IoU 仍維持 90%+

### 10.3 學習心得
- 深度學習的優勢在於「學習語意」而非「硬編碼規則」
- 資料切分方式很重要，時間序列資料要用時間順序切分
- Val Loss 是檢測 overfitting 的重要指標
- 視覺化比較（overlay）是理解模型行為的最直觀方式

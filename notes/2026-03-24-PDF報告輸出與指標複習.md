## 三、主要踩坑與解法

### 3.1 Header 佔整頁

**原因**：Header 內含漸層背景與多行文字，高度過大  
**解法**：CSS 強制 `height: 34px; display: flex; align-items: center;`，副標題 `display: none`

### 3.2 雷達圖跑到錯誤頁

**原因**：雷達圖的 HTML class 是 `"summary-section radar-section"`（兩個 class 並存），而 `.summary-section { page-break-before: always }` 的 CSS 規則同時套用到雷達圖，導致它被強制換頁  
**解法**：改用雙類選擇器提高優先度：
```css
.summary-section.radar-section { page-break-before: avoid !important; }
.summary-section:not(.radar-section) { page-break-before: always !important; }
```

### 3.3 P3 三個區塊間距不一致

**原因**：`.scenario` 有 `margin-bottom: 52px`（SCENARIO_GAP），加上雷達圖的 `margin-top: 18px`，導致「日間建築物 → 雷達圖」實際間距是 70px，遠大於「雷達圖 → 結論」的 18px  
**解法**：在 Python 中替最後一個 scenario（日間建築物）加上 `.pre-radar` class，CSS 將其 `margin-bottom` 歸零，由 `RADAR_GAP` 統一控制：
```python
html_text = html_text[last_pos:].replace(
    '<section class="scenario"',
    '<section class="scenario pre-radar"', 1
)
```
```css
.pre-radar { margin-bottom: 0 !important; }
.summary-section.radar-section { margin-top: 18px !important; }
.summary-section:not(.radar-section) { margin-top: 18px !important; }
```

### 3.4 圖片被裁切，不同模型看起來一樣

**原因**：`object-fit: cover` 會以中心點裁切圖片填滿固定高度，導致天空邊界資訊被截掉  
**解法**：改為 `object-fit: contain`，等比例縮放顯示完整圖片，背景填淺灰 `#f5f5f5`

## 五、Precision 與 Recall 公式複習

$$\text{Precision} = \frac{TP}{TP + FP} \quad \text{（預測為天空中，真的是天空的比例）}$$

$$\text{Recall} = \frac{TP}{TP + FN} \quad \text{（真正是天空中，有被預測到的比例）}$$

### 直覺理解兩個反直覺情境

**情境 A：整張圖都預測為天空 → FP 很高，但 Recall = 1**
- 模型「來者不拒」，每個天空像素都抓到（FN = 0）→ Recall 完美
- 但把非天空也當天空（FP 很多）→ Precision 很低
- Recall 的分母只有 `TP + FN`，與 FP 完全無關

**情境 B：漏預測很多（FN 高），但 Precision = 0.999**
- 模型「寧可不說，不能說錯」，只在非常確定時才預測天空（FP ≈ 0）→ Precision 近乎完美
- 但保守到漏掉大量天空（FN 很多）→ Recall 很低
- Precision 的分母只有 `TP + FP`，與 FN 完全無關

### 一句話記憶
> **Recall 只管「天空有沒有被找到」；Precision 只管「預測天空的準不準」**  
> 這就是為什麼需要 **IoU** 同時懲罰 FP 和 FN，才能全面評估模型好壞。

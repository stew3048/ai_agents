## 解讀：為什麼 DL 在多數情境較好？各情境該看什麼指標？

### 為什麼 DL 在多數情境比較好？

1. **任務專用 vs 通用模型**
   - **DL（U-Net）**：在「天空分割」資料上訓練，學的是「什麼是天空、什麼不是」，直接優化 IoU/邊界。
   - **SAM**：通用分割模型，用「提示（一點/框）」決定要分割哪一塊，**沒有為「天空」這個類別特別訓練**。提示給錯或不足時，容易整塊偏掉（例如 night 時點到建築、sea-sky 時框到海）。

   **SAM 的機制補充**：SAM 會看**整張圖的語意空間**（image encoder 產出整圖 embedding），再根據 prompt 在這個空間裡找「區域結構合理、一致」的連通區來分割。在困難情境（天海一線、多霧、夜間、提示不足或給錯）下，語意上「天空 vs 海/霧/暗區」本就模糊，若 prompt 又偏掉，模型會在**同一套語意空間**裡選到「對它來說結構合理、但其實不是天空」的區域，結果就是**整塊偏掉**（例如整片海、整片霧、或建築被當成一個連通區域），而不是只錯一點邊界。

2. **困難情境下提示的極限**
   - **sea-sky**：外觀相近，DL 學過邊界與紋理，SAM 只靠上方框/點，容易把海也割進來 → DL 的 FP 較低、IoU 較高。
   - **heavy-occlusion**：天空被樹枝等擋住，SAM 多點提示容易割成「多塊物體」或漏掉天空，DL 學過「天空在上方、有連續性」→ DL 的 IoU 較高、FP/FN 都較低。
   - **night**：亮度低、對比差，SAM 常割錯區域（例如整片黑都當天空或反過來），DL 在類似夜間資料上學過 → 平均上 DL 較穩。

3. **urban / default 裡 SAM 的 FP 較低**
   - 在這些情境 SAM 常「割得比較保守」（預測天空較少），所以 **FP 低**，但 **FN 高**（漏掉不少真天空）→ IoU 往往還是 DL 高。也就是說：SAM 不是「更準」，而是「少預測一點天空」，用少報換取少錯報。

---

### 每個情境應該優先看什麼指標？

| 情境 | 主要問題 | 建議優先看的指標 | 理由 |
|------|----------|------------------|------|
| **no-sky** | 沒有天空卻被模型標成天空 | **FP** | 沒有真天空可漏（FN 無意義），任何「預測為天空」都是誤報，FP 直接代表錯誤程度。 |
| **sea-sky-confusable** | 海與天易混淆，易把海標成天 | **FP、IoU** | FP 高 = 把非天空（海）當天空；IoU 同時反映邊界是否準。FN 通常不高，可當次要。 |
| **heavy-occlusion** | 天空被擋住，易漏標或多標 | **FN、IoU** | 漏標被擋住的天空（FN）是主要風險；IoU 看整體覆蓋與邊界。 |
| **night** | 暗、對比低，易錯標或漏標 | **IoU、FP、FN 都看** | 沒有單一主因，FP（把建築/地景當天）和 FN（漏掉暗天空）都會發生，IoU 是綜合。 |
| **urban** | 建築邊界、屋頂易與天空搞混 | **IoU、FP** | 邊界與「屋頂當天空」的 FP 最重要；FN 可當次要。 |
| **default** | 混合情境 | **IoU** | 用 IoU 當總體，再依圖內容看 FP/FN 誰在惡化。 |

---

### 若某情境「SAM 的 FP 大幅下降，但 IoU / FN 反而變差」代表什麼？

- **FP 下降**：SAM 預測為「天空」的像素變少 → 比較**保守**（少報天空）。
- **FN 上升**：漏掉的「真天空」變多 → 保守的代價是**漏標**。
- **IoU 下降**：通常來自 FN 變多（漏掉真天空）或邊界變差，整體重疊變少。

**一句話**：SAM 在該情境傾向「少割一點」，所以**錯報（FP）變少，但漏報（FN）變多**，屬於**用漏標換取少誤報**的取捨，不是單純「SAM 變好」。

- 若應用**最在意「不要把非天空標成天空」**（例如下游依天空 mask 做曝光，不能把建築當天）：FP 下降是好事，可以接受 FN 略升。
- 若應用**最在意「所有天空都要標到」**（例如天空覆蓋率統計）：FN 上升是壞事，這時 DL 的較低 FN 反而較適合。

# VLM（CLIPSeg）適用情境：理論推論與實測對照

> 從 VLM 的機制推論它「理論上」適合哪些情境，並與三方法實測結果對照。  
> 日期：2026-02-07

---

## 一、VLM（CLIPSeg）的機制簡述

- **輸入**：一張圖 + 文字 prompt（例如 `"sky"`）。
- **機制**：在 **vision–language 共享語意空間** 中，比對「圖中各區域」與「文字 'sky'」的語意相似度，decoder 產出與「sky」相似的區域為前景。
- **與 DL / SAM 的差異**：
  - **DL（U-Net）**：任務專用，學「像素/邊界是否為天空」，有明確的覆蓋目標（盡量對齊 GT）。
  - **SAM**：通用分割，依**空間提示**（點/框）決定「割哪一塊」，沒有語意類別「天空」。
  - **VLM**：依**語意**（「像 sky 的區域」）分割，**沒有空間提示**，也沒有「盡量畫滿天空」的訓練目標。

---

## 二、從理論推論：VLM 適合的情境

### 1. 適合 VLM 的情境（理論）

| 情境 | 理論理由 |
|------|----------|
| **No-sky** | 圖中沒有天空時，語意查詢 "sky" 在整張圖都不該有高反應 → **FP 應極低**。DL 易依顏色/亮度誤判，SAM 有空間提示可能誤觸發；VLM 純語意，最穩。 |
| **Sea-sky / 天海一線** | 外觀上海與天相似，但**語意上**「sky」與「sea」在 CLIP 空間可區分。VLM 依語意而非僅外觀 → **少把海當天空（FP 低）**，有機會 IoU 較佳。 |
| **Heavy-occlusion** | 天空被樹/建築切割成多塊；SAM 的點/框易落在非天空上導致整塊錯。VLM 問「哪裡像 sky」→ 樹縫、建築縫中**語意像天空的區塊**可被標出，不需「點對位置」。 |
| **Night** | 夜間外觀暗、對比低，DL 易漏檢。VLM 的「sky」語意可涵蓋暗天空，不依賴亮度/顏色，有機會**補足外觀難認**的問題。 |

共通點：**語意先驗**（「像 sky」）能補足或取代「空間先驗」（點在上方）或「外觀先驗」（顏色/紋理），且**不需精準的點/框**時，VLM 理論上較有利。

### 2. 不適合或需謹慎使用 VLM 的情境（理論）

| 情境 | 理論理由 |
|------|----------|
| **Urban** | 都市場景中天空常被建築邊緣、玻璃、天際線切割成**小塊、複雜邊界**。VLM 輸出解析度有限、decoder 易保守 → **易少標（FN 高）**；且沒有「盡量覆蓋 GT 天空」的訓練目標，邊界與小塊天空易漏。DL 專用任務、SAM 上方 box 覆蓋完整，理論上更穩。 |
| **極度依賴邊界精度** | 若應用需要 pixel-level 邊界，VLM 的粗糙輸出與保守傾向可能不如 DL。 |

---

## 三、與實測結果對照

三方法（DL / SAM / CLIPSeg）在 diagnostic 166 張上的情境彙總：

- **No-sky**：CLIPSeg FP 最低（≈0），優於 SAM、DL → **與理論一致**。
- **Sea-sky**：CLIPSeg IoU 最高、FP 最低；SAM FN 最低 → **VLM 語意區分海天與理論一致**；FN 取捨見報告。
- **Heavy-occlusion / Night**：CLIPSeg 平均 IoU 與 FP 最佳；FN 以 DL 最低 → **VLM 在整體與少誤報上與理論一致**；要少漏天空可選 DL。
- **Urban**：DL 與 SAM 皆優於 CLIPSeg（IoU 較高、FN 較低），CLIPSeg FN 明顯偏高 → **與「VLM 在複雜邊界/小塊天空易保守、FN 高」的推論一致**。

結論：**依理論推論的「VLM 適合 / 不適合」情境，與實測相符**；可依此做選模與後續實驗規劃。
